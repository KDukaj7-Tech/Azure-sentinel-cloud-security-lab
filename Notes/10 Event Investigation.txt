Overview

After confirming that Windows event logs were successfully ingested into the Log Analytics Workspace, an investigation was performed using Kusto Query Language (KQL) to analyse authentication events generated by the virtual machine.

The investigation focused on Event ID 4624, which represents a successful Windows logon.

KQL Query Used:
Event | where EventLog == "Security" | where EventID == 4624 | where TimeGenerated > ago(24h) | project TimeGenerated, Computer, EventID, RenderedDescription | take 10

Investigation Findings

The query returned multiple successful logon events generated by the Windows Server virtual machine.

The RenderedDescription field was examined to identify the type of logon and determine whether the activity appeared legitimate.

During the investigation, the following logon types were observed:

Logon Type 2 – Interactive logon (user logging on locally).
Logon Type 3 – Network logon.
Logon Type 5 – Service logon generated by Windows services.
Logon Type 7 – Workstation unlock.

One of the investigated events showed:

Account Name: VMWindowsCloud$
Process Name: C:\Windows\System32\services.exe
Source Network Address: Not populated

These values indicate a normal Windows service account rather than a user performing an interactive login.

Conclusion

No suspicious activity was identified during this investigation.

The observed events were consistent with expected Windows operating system behaviour, demonstrating how KQL can be used to validate authentication activity and distinguish legitimate system events from potential security incidents.
